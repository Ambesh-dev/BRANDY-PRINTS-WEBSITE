# Brandy Prints - Official Collector Kits & Creator Merchandise Store

Welcome to **Brandy Prints**! A luxury, ultra-premium web platform designed specifically for unboxing collector boxes, merchandise drops, die-cut holographic stickers, VIP access passes, and custom creator kits for YouTubers and tech communities.

---

## 🌟 Key Features

1. **Cyber & Pastel Neon Aesthetics**:
   - High-contrast dark cyberpunk themes with luminous cyan & magenta glow inspired by the **AI Bunny Collector Kits**.
   - Live interactive edition switcher in the Hero section (Cyber Hacker vs. Girl Tech edition).

2. **Interactive Anatomy & Unbox Explorer**:
   - Deep-dive interactive breakdown of the kit:
     - 1200 GSM Velvet Soft-Touch Rigid Box
     - Die-cut waterproof vinyl stickers
     - VIP Access passes & event tickets with scannable QR codes
     - Personalized letter to tech learners with custom envelope
     - Postcards & fine art landscape prints
     - Code sprint to-do lists & dot-grid notepads

3. **YouTube Channel & Creator Spotlight**:
   - Direct integration for your YouTube channel.
   - 4K unboxing video player embed.
   - Subscriber counter and verified creator badges.

4. **Product Catalog & Filtering**:
   - Filter by categories (*Collector Kits, Custom Channel Merch, Sticker Packs, VIP Passes, Stationery*).
   - Real-time search and sorting (price, rating, featured).
   - Quick view modal with complete itemized checklist and specifications.

5. **Instant WhatsApp Orders & Cart Drawer**:
   - Integrated shopping bag with live free shipping threshold counter.
   - 1-click "Order on WhatsApp" that formats item quantities, names, and delivery address into a ready-to-send message.

6. **Custom Channel Merch Builder for YouTubers**:
   - A dedicated quote request form where YouTubers can select their preferred aesthetic style, items to include, and order quantity.
   - Submissions automatically appear in the Admin Panel for review.

---

## 🛠️ Built-in Admin Management System (LIVE CMS)

Click the **Admin Panel** button in the top navigation or footer to access the full control dashboard:

- **Product Manager**:
  - Add new products and collector kits.
  - Edit titles, prices, discount strike-throughs, badges, and stock availability.
  - Customize the exact list of items included inside each kit box.
  - Upload photos or paste image URLs.
  - Delete products with one click.
- **Website Branding & Customization**:
  - Website Name (e.g. `Brandy Prints`)
  - Choose between **Text Typography Logo** or **Upload Custom Image Logo**
  - Edit Hero Headline, Subtitle, and Top Announcement Bar notice
  - Update YouTube Channel Name, Subscriber count, Channel Link, and Video Embed ID
  - Update WhatsApp Phone Number and Contact Email
- **Creator Inquiries & Order Tracker**:
  - View all custom kit quote requests submitted by creators.
  - Change status (*New, In Discussion, Proof Approved, In Production, Completed*).
  - One-click button to chat with the customer directly on WhatsApp.
- **Backup & Factory Reset**:
  - Download full JSON backup of all products and settings.
  - Restore anytime from a backup file.
  - One-click Reset to factory default data.

## 🚀 How to Run Locally

You can simply double-click `start-website.bat` or run in your terminal:

```bash
npm run dev
```

Then open `http://localhost:5173` in your browser.

To create a production-ready build for hosting:
```bash
npm run build
```
This generates an optimized static bundle in the `dist/` directory, ready to deploy to Vercel, Netlify, Firebase Hosting, or GitHub Pages.
